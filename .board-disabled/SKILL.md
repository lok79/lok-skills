# Board — 项目工单看板

文件是会话所在工作区根目录的 `BOARD.md`，即 `AGENTS.md`、`CONTEXT.md` 所在的目录——不是用户主目录，也不进 `~/.agents/`。

用户打开本项目根目录的 `BOARD.md` 一个文件，就要能回答：哪些工单在飞、各自到哪一步、下一步该粘贴什么。除"最后一笔"外，看板全部由会话写入——用户零维护。

术语（看板 / 焦点 / 澄清条目 / 阶段 / 审查结束 / 最后一笔 / 更新时间）以各工作区 `CONTEXT.md` 为准。

## 格式

```markdown
# 看板

## 进行中
### <工单名>
- 阶段：<待实现|实现中|待审查|审查中|审查结束>
- 始：<YYYY-MM-DD HH:MM:SS>
- 下一步：<一条可粘贴的命令，或一句等价指引>
- 更新：<YYYY-MM-DD HH:MM:SS>

## 澄清中
- <工单名> · <澄清进行到哪，一句话> · 更新 <YYYY-MM-DD HH:MM:SS>
```

时间戳一律 `YYYY-MM-DD HH:MM:SS`，本机时区。进行中区允许多节并列（多焦点并行）。

## 触发点

| 时刻 | 动作 |
| --- | --- |
| 澄清会话开局（第一轮问答时） | `## 澄清中` 新增一行 |
| 澄清每推进一轮 | 更新该行的进行描述与更新时间 |
| 工单产出（spec/工单文件就绪，等用户粘贴走实现） | 该行升级为 `## 进行中` 一节：阶段=待实现、始=现在、下一步=要粘贴的命令 |
| 实现会话开跑（工单被粘贴进来） | 阶段=实现中、更新下一步 |
| 实现收尾 | 阶段=待审查、下一步=审查命令 |
| 审查会话开跑 | 阶段=审查中 |
| 审查收尾 | 阶段=审查结束——停，等待最后一笔 |

## 规则

- **最后一笔只属于用户**：审查结束的条目由用户亲手删除整节退场。会话永不代替用户做最后一笔，也永不删任何条目。
- **无历史**：退场即消失，不写归档区、不记流水。
- **流产澄清不清理**：搁置的澄清条目留着，靠陈旧的更新时间自曝，由用户手工删。
- **漏写无补救**：会话中断漏更新时，不回溯修补；下一个触发点自然纠正，滞后期由更新时间暴露。
- **工单名**用 feature 目录名（如 `005-搜索`）；无目录的手动流用一句可辨识的短名。
